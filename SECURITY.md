# Security

Please do not report security problems in public issues.

Use GitHub's private vulnerability reporting on this repository (the **Security** tab, then **Report a vulnerability**). We will reply as soon as we can.

If that option is not shown yet, open an issue titled only "Security contact request", with no details at all. A maintainer will reply and arrange a private way to talk.

The platform's security design does not rely on this code being secret.
