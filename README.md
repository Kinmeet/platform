# Kinmeet platform

The website and platform for Kinmeet, a planned UK volunteer-run network of local groups that hold small, free, all-ages meets in parks and public spaces.

This is one Nuxt app running on Cloudflare Workers, with D1, R2 and KV for storage.

## Coding in the open

This repository is public so that anyone can see how the platform works and how it handles data. It is **not open source**: no licence to reuse, copy, modify or distribute the code is granted. See [NOTICE.md](NOTICE.md).

Security never depends on the code being secret. No secrets or personal data are ever kept in this repository, its issues or its pull requests.

## Who builds this

The platform is built by a team of AI agents working for Kinmeet's founder, who approves plans and every live release. Each agent has a fictional persona (a name and a role) so that work can be attributed and discussed. The personas are not real people.
